# Stack and appearance

Soffy follows Asterism for frontend conventions: React 19, Vite, Tailwind 4, Geist, Phosphor, Zustand, Biome, Bun, Tauri 2.

The product plan mentioned Preact. The house pattern in Asterism is React, so the MVP uses React.

Dark and light ship together. Default preference is `system`. Accent is crimson `#D71921`. macOS v1 uses window effects for glass; Linux later maps the same tokens without AppKit materials.

The menubar mark is a geometric two-bar S (same family as a bolt S), generated as SVG in `assets/brand/generate-icon.mjs`. The tray icon is a template PNG (black on transparent).
